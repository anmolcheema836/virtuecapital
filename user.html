Redesigned User Flow

Optimized path for "Ordering a Box of Doughnuts". The new flow brings the ordering process in-house and reduces clicks by 40%.

Start Flow
User Action

1. Homepage (Landing)

User arrives at the homepage and views the premium hero image and pickup announcement.

Decision: User scrolls down to view the "Fresh Daily Doughnuts" Menu Grid.

UX Rationale: The IA was flattened. Users no longer need to click through tabs to discover what products are available.
User Action

2. Product Discovery

User views all available doughnuts in a clean, visual grid layout.

Action: User clicks the "Add to Cart" button directly on a product card.

UX Rationale: Keeps the user anchored to the menu, preventing the "context-switching" fatigue present in the original site.
System Response

3. Slide-Out Cart Drawer

A cart drawer slides out from the right side of the screen instantly.

Action: User reviews their order subtotal and clicks "Proceed to Checkout".

Heuristic Applied: Visibility of System Status. The user instantly knows their item was added without being redirected to a new page.
User Action

4. Integrated Checkout

User is taken to a clean, single-page checkout hosted directly on Yonni's website.

Action: User inputs Pickup Time, Contact Info, and Payment Details.

UX Rationale: Solves the client brief requirement by bringing the checkout "in-house" rather than bouncing to a 3rd party Shopify page.
Endpoint

5. Order Confirmation

User clicks the "Confirm Order & Pay Now" button.

Prototype intentionally stops here.

Client Constraint: The brief explicitly states the redesign must not go beyond payment confirmation.
End Flow
